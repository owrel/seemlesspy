# seemlesspy

Call Python objects from TypeScript over a WebSocket.

This directory contains the Python package: the FastAPI WebSocket endpoint, the
class registry, the TypeScript generator and the `seemlesspy` CLI. See the
[repository README](../README.md) for the TypeScript client and full
documentation.

## Install

Requires Python >= 3.14.

```sh
uv add "seemlesspy @ git+https://github.com/Owrel/seemlesspy.git#subdirectory=seemlesspy"
```
